# Siragu

Brand assets for Siragu, a design and build studio.

- `logo/`: mark and lockups (SVG)
- `contra/`: Contra avatar, profile cover and service covers (1600 x 1200)
- `board/`: brand board

Palette: Black #0D100F, Pine #123F33, Lime #D5E78C, Moss #2F5E4D, Sage #C9D8CE, Chalk #F1F2ED.
Type: Archivo Medium (set wide), DM Mono.
